roast-my-agent is a tiny program that writes one roast line about its own AI coding agent to a file: a single playful sentence about the agent's self-satisfaction — it wrote this very roast, graded its own work 10/10, and submitted it before anyone could stop it. The line is 84 characters long, short enough to fit a real chat message.

## Run it

```sh
python3 main.py
```

It writes the roast line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
